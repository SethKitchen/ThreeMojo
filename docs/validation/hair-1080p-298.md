# A 1080p strand-hair frame on a named cloud machine (#298)

This report benchmarks the 1920 x 1080, 60 frames-per-second target of issue [#298](https://github.com/SethKitchen/ThreeMojo/issues/298) on one named machine with the CPU rasterizer. **The result is FAIL.** The median frame takes 5,550 milliseconds, about 333 times the 16.667 millisecond budget. The GPU half of the target needs a device run, which is still pending. This report makes no claim for other hardware.

## Machine

| Property | Value |
|---|---|
| CPU | Intel Xeon Processor at 2.80 GHz, as `/proc/cpuinfo` reports it |
| Logical cores | 4, on a shared cloud virtual machine |
| GPU | None |
| Operating system | Linux 6.18 |
| Compiler | Mojo 1.1.0 (`8189361e`) with MAX 26.6.0, built with `--target-accelerator=sm_80` so that the GPU module compiles |
| Load | Other jobs shared the machine. The one-minute load average was 16.5 before the run and 18.4 after it, on 4 cores. The bench process got 42.6 seconds of CPU time in 120.8 seconds. |

The load makes these times slower than an idle run of the same machine. The 60 fps verdict does not depend on it: the frame would have to be about 333 times faster.

## Scene and quality

`bench/hair_frame_bench.mojo` is the [#729](https://github.com/SethKitchen/ThreeMojo/issues/729) bench. This change adds the CPU model, a visible strand count and a PASS or FAIL line against the budget.

| Property | Value |
|---|---|
| Image | 1920 x 1080 |
| Groom | The default groom of a six-foot male: 10,185 strands, 68,495 points, 6.7 points a strand |
| Visible strands | 4,498 in the last timed frame. A strand is visible when one of its points projects into the image and no stored depth is nearer than that point. The head sphere hides the rest. |
| Coverage | One-pixel strands at opacity 0.65, with hashed strand coverage (`STRAND_LINE_COVERAGE`) |
| Self-shadow | The density volume at 24 cells a side, one directional light and ambient light |
| Simulation | Guides only, against a baked head collider, in wind |
| Triangles | 700,904 for the rest-pose scene, head included |
| Raster workers | 4, every logical core |
| Frames | 2 warm-up frames, then 10 timed frames |

## Frame-time breakdown

| Stage | p50 | p95 | max |
|---|---:|---:|---:|
| Guides-only step and write | 38.0 ms | 66.5 ms | 66.5 ms |
| Density, self-shadow, shading and upload | 79.0 ms | 125.9 ms | 125.9 ms |
| `cpu render`: triangle preparation, lighting, rasterization and resolve | 5,420 ms | 6,196 ms | 6,196 ms |
| **Whole frame** | **5,550 ms** | **6,324 ms** | **6,324 ms** |
| `cpu prepare` alone (diagnostic, not in the frame) | 2,776 ms | 3,171 ms | 3,171 ms |

One rest-pose render with parts hidden:

| Visible | Render time |
|---|---:|
| Nothing (background only) | 73 ms |
| Head only | 196 ms |

The bench output ends with this line:

```text
60 fps at 1920x1080, frame with cpu render: FAIL (median 5550.457174 ms, budget 16.666666666666668 ms)
```

## Findings

- **The CPU path cannot meet the target on this machine.** The hair stages alone take about 117 milliseconds, seven times the budget. Strand triangle preparation and rasterization take about 5.4 seconds.
- **Strand drawing is the bottleneck**, as on the 12-core desktop in the [#729 report](hair-frame-729.md). There, the whole frame took 791 milliseconds.
- **The GPU result is pending.** The device rasterizer needs tile binning before a 1080p frame is practical. The repository owner reports GPU strand drawing work on a separate branch: 16 x 16 tile binning on a TITAN RTX, with about 38 milliseconds for the kernel and the read back at 1080p, and about 2.1 seconds of host packing. That work is not on this branch, and this report does not repeat or verify it.

## Run the GPU stages on a device

The same bench times the GPU path when a device is present and the command line gives a size. On a machine with a supported GPU and MAX installed:

```sh
mkdir -p .cache/hair-frame
.venv/bin/mojo build -I . --Werror -o .cache/hair-frame/bench \
  bench/hair_frame_bench.mojo
.cache/hair-frame/bench 10 gpu 240 135
.cache/hair-frame/bench 10 gpu 1920 1080
```

Measure a small size first. The current device rasterizer walks every primitive for each pixel. The GPU verdict line reports the median of the simulation, the shading and the GPU raster stages against the same budget. A PASS needs that line at 1920 x 1080 on a named GPU, with its driver and the visible strand count.

On a machine without a GPU, add `--target-accelerator=sm_80` to the build. The bench then runs the CPU stages only.

## Run the CPU stages

```sh
S=.cache/hair-frame
mkdir -p $S
.venv/bin/mojo build -I . --target-accelerator=sm_80 --Werror \
  -o $S/bench bench/hair_frame_bench.mojo
$S/bench 10
```
